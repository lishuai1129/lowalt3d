## 1. 总体目标

最终要得到三类成果：

### 1.1 材质感知 3DGS 研究成果

在 3D Gaussian primitive 中增加材质属性：

```text
Gaussian_i = {
  position,
  scale,
  rotation,
  opacity,
  SH color,
  material_logits
}
```

其中：

```text
material_logits ∈ R^K
K = 材质类别数
```

训练后：

```text
material_prob_i = softmax(material_logits_i)
```

该部分是论文核心创新。

### 1.2 Cesium 可视化成果

用于展示真实三维建筑外观：

```text
带照片纹理 mesh
真实地理坐标
3D Tiles / glTF / GLB
Cesium / Cesium for Unreal 可加载
```

建议由 OpenDroneMap / Metashape / ContextCapture 生成，而不是直接用 3DGS mesh 替代。

### 1.3 Wireless 射线仿真成果

用于通信仿真：

```text
显式 mesh
面片材质类别
电磁参数
ENU / UTM 米制坐标
按材质拆分 OBJ
```

输出示例：

```text
roof.obj
wall_or_concrete.obj
road_ground.obj
vegetation.obj
glass_or_window.obj
material_parameters.csv
coordinate_system.txt
```

## 11. 材质感知 3DGS：Gaussian primitive 添加材质属性

这是开题报告中的核心方法。

### 11.1 输入

```text
outputs/scene01_uav_pgsr/point_cloud/iteration_7000/point_cloud.ply
data/scene01_uav/undistorted/sparse_txt/cameras.txt
data/scene01_uav/undistorted/sparse_txt/images.txt
outputs/scene01_uav_material2d/pred_masks_all/*.png
data/scene01_uav/material/classes.txt
```

### 11.2 Gaussian 材质属性定义

对每个 Gaussian 增加：

```text
material_logits ∈ R^K
```

材质概率：

```text
material_prob = softmax(material_logits)
```

### 11.3 推荐训练策略

先采用稳定版本：

```text
冻结 Gaussian 几何、颜色、透明度；
只学习 / 估计 material_logits。
```

不要一开始就联合优化几何和材质。

### 11.4 可微训练版本

如果修改 3DGS rasterizer：

```text
M(p) = Σ_i w_i softmax(l_i)
L_mat = CE(M(p), Y(p))
```

其中：

```text
w_i：Gaussian 对像素的 alpha blending 权重
l_i：第 i 个 Gaussian 的 material_logits
Y(p)：2D 材质 mask
```

### 11.5 工程可落地版本：多视角投票估计 material_logits

如果暂时不改 CUDA rasterizer，先做投票版：

```text
1. 读取 Gaussian 中心点
2. 将中心点投影到多个 COLMAP 相机
3. 在对应 pred_mask 中读取材质类别
4. 按可见视角、深度、opacity 加权投票
5. 得到每个 Gaussian 的 material_prob
6. 保存 material_logits
```

运行：

```bash
python scripts/train_gaussian_material_logits.py \
  --gaussians outputs/scene01_uav_pgsr/point_cloud/iteration_7000/point_cloud.ply \
  --cameras data/scene01_uav/undistorted/sparse_txt/cameras.txt \
  --images data/scene01_uav/undistorted/sparse_txt/images.txt \
  --mask_dir outputs/scene01_uav_material2d/pred_masks_all \
  --classes data/scene01_uav/material/classes.txt \
  --out_dir outputs/scene01_uav_material3d \
  --iterations 5000 \
  --lr 0.05
```

预期输出：

```text
outputs/scene01_uav_material3d/gaussian_material_logits.pt
outputs/scene01_uav_material3d/gaussian_material_labels.csv
outputs/scene01_uav_material3d/gaussian_material_points_colored.ply
```

## 12. Gaussian 材质融合到 Mesh

通信仿真不能直接使用 Gaussian，需要显式三角面片。

输入：

```text
outputs/scene01_uav_pgsr/mesh.ply
outputs/scene01_uav_pgsr/point_cloud/iteration_7000/point_cloud.ply
outputs/scene01_uav_material3d/gaussian_material_logits.pt
```

运行：

```bash
python scripts/fuse_gaussian_material_to_mesh.py \
  --mesh outputs/scene01_uav_pgsr/mesh.ply \
  --gaussians outputs/scene01_uav_pgsr/point_cloud/iteration_7000/point_cloud.ply \
  --logits outputs/scene01_uav_material3d/gaussian_material_logits.pt \
  --classes data/scene01_uav/material/classes.txt \
  --out_mesh outputs/scene01_uav_material3d/mesh_material_from_gaussian.ply \
  --out_faces outputs/scene01_uav_material3d/face_materials_from_gaussian.csv
```

融合方法：

```text
for each mesh face:
  face_center = triangle center
  neighbor_gaussians = kNN(face_center)
  material_prob_face = weighted average(material_prob_gaussian)
  material_id = argmax(material_prob_face)
```

权重建议：

```text
w_i = opacity_i * exp(-dist(face_center, gaussian_center)^2 / (2σ_i^2))
```

## 17. 摄影测量纹理模型与 Cesium

3DGS / PGSR 输出通常不是传统 UV 纹理 mesh。若要 Cesium 中展示真实建筑纹理，建议使用 OpenDroneMap。

### 17.1 准备 ODM 输入

```bash
cd ~/projects/lowalt3d

rsync -av data/scene01_uav/images_full/ odm_projects/scene01_uav/images/
```

### 17.2 运行 ODM

```bash
docker run -ti --rm \
  -v ~/projects/lowalt3d/odm_projects:/datasets \
  opendronemap/odm \
  --project-path /datasets scene01_uav \
  --orthophoto-resolution 3 \
  --mesh-size 600000 \
  --texturing-data-term area \
  --feature-quality high \
  --pc-quality high \
  --use-exif
```

## 18. 地理配准

### 18.1 EXIF GPS 粗配准

无人机图像带 GPS，可用于粗地理配准。

但普通 GPS 存在误差：

```text
水平误差：约 1-5 m 或更大
高程误差：通常更不稳定
```

### 18.2 推荐精配准方式

```text

2. GCP 地面控制点
3. 已知建筑角点 / 道路交点
4. 与 Cesium 底图手动校正偏移
```

```text
WGS84 / EPSG:4979
```

Wireless：

```text
ENU / UTM 米制坐标
```

## 19. 大范围区域低成本建图方法

如果 UAV 全覆盖太费时，采用分层建图：

```text
卫星 / 正射影像 / DEM / OSM：大范围粗模型
少量 UAV：重点区域高精补拍
材质感知 3DGS：关键区域材质学习
```

实施：

```text
1. OSM 获取建筑 footprint
2. DEM / DSM 估计建筑高度
3. 生成 LOD1 / LOD2 粗建筑
4. UAV 只拍关键区域
5. 用 UAV 高精模型替换重点区域
6. 全部统一到 ENU / UTM
```

论文对比：

```text
A. 全 UAV 高精模型
B. 卫星 / OSM / DEM 粗模型
C. 粗模型 + 少量 UAV 重点区补拍
```

指标：

```text
采集影像数量
采集时间
建模时间
LoS 判断准确率
路径损耗差异
覆盖率差异
```

## 20. 论文实验对比

必须保留三种方法：

```text
A. 无材质模型：所有建筑面统一 concrete
B. 2D 投影材质模型：2D mask 直接投影到 mesh
C. 材质感知 3DGS：Gaussian material_logits → mesh
```

评价指标：

```text
材质识别：
  pixel accuracy
  mIoU
  per-class IoU

三维材质：
  face confidence
  neighbor consistency
  unlabeled face ratio

通信仿真：
  LoS ratio
  path loss mean / std
  coverage ratio
  blocking material distribution

效率：
  UAV 图像数量
  COLMAP 时间
  PGSR 时间
  材质训练时间
  仿真时间
```
