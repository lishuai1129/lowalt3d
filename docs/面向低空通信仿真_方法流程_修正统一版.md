## Stage 1 · 多源几何：LOD1 底座 + UAV 关键区高精重建

**目标**：大范围低精度底座（免费卫星/OSM）+ 关键区高精材质模型（少量 UAV），实现"降采集量"。

### 1.1 大范围底座（程序化，非 3DGS）
- 数据：Google Earth Engine / USGS 正射影像（0.3–2 m）+ DEM；**优先叠加 OSM building footprint**（比从正射分割足迹更稳）。
- 足迹 + 高度（DEM 轮廓内最大高程 − 地面高程）→ **拉伸生成 LOD1 盒子 mesh**。
- 材质：底座统一给 `concrete` 默认（诚实标注为"低置信底座"）。
- 坐标：WGS84 → 本地 UTM/ENU 米制。

### 1.2 UAV 关键区高精重建
- 采集：关键区多航线（航向≥80%、旁向≥70%；单镜头补**环绕+井字**航线拿立面）。
- COLMAP SfM → 稀疏点云 + 位姿；有 RTK/PPK 直接带地理坐标，否则 GCP 配准到 UTM。
- 该区进入 Stage 2 的材质感知 3DGS。

### 1.3 对齐拼接（对应开题"关键问题①"）
- UAV 模型 → 底座坐标系：3–5 同名角点**相似变换(R,T,s)**粗配准 + **Point-to-Plane ICP** 精配准。
- 用 DEM 局部地面高程做垂直校正；密集区局部非刚性微调（平滑约束）。
- 输出：底座(LOD1) + 关键区(高精材质 mesh) 的**统一米制场景**。

> 修正说明（M2）：**3DGS 只在 UAV 覆盖的关键区跑**，非覆盖区用 LOD1。这既 technically sound，又保留"多源协同降采集量"的创新论述。若要更贴开题原文，可选做 SkySplat 式**多时相卫星 3DGS**做粗底座，但精度仅米级、工作量大，列为可选。

## Stage 2 · 材质感知 3DGS（关键区，联合重建）

对应开题研究内容②，是核心创新，务必做**可微联合**版。

### 2.1 材质类别（统一，M3）
面向电磁、可从航拍 RGB 较可靠区分的 6 类 + 兜底：
`concrete(混凝土/水泥立面) / glass(玻璃幕墙窗) / metal(金属屋顶板/幕墙) / brick(砖) / tile(瓦屋顶) / ground(地面道路) / vegetation(植被)`。
- 到 P.2040 映射：concrete/brick/glass/metal 直接对应；tile≈ceramic/concrete 近似；stone 并入 concrete；ground/vegetation 用 P.2040 地面/植被介电值。
- ⚠️ **金属 vs 混凝土**纯 RGB 难分但电磁差异极大（金属近全反射）——列为识别风险，用多视角一致性 + 高光/纹理特征辅助。

### 2.2 可微材质分支（M4，主线）
- 每高斯加 N 维材质向量 `m∈R^N`，随 alpha-blending 可微渲染合成像素材质图 `p=Σαᵢmᵢ/Σαᵢ`，softmax→argmax。
- 与 RGB 共享光栅化，端到端反传。**这是需要改 3DGS/PGSR CUDA rasterizer 的硬工程**（在 `diff_plane_rasterization` 加材质通道 + 反传）。
- 损失：`L = L_rgb + λ·L_mat + γ·L_cons`
  - `L_rgb` = L1 + SSIM；`L_mat` = 像素级交叉熵；`L_cons` = 多视角材质分布 KL 一致性。
  - λ 渐进：<5k iter=0.1（先收几何）→ 5k–15k=0.3 → >15k=0.5。
- 半监督：500–800 张 LabelMe 人工标注监督 + SegFormer-B3 伪标签(conf>0.8) + 多视角一致性。

### 2.3 降风险 fallback（投票版）
若可微 CUDA 分支受阻：退化为 **PGSR 几何 + 多视角投影投票材质**（即原工作流做法，近似 Huynh 2025 material-informed GS）。
- 论文定位：fallback/baseline，**可微版才是 novelty**；必须做消融对比二者。

### 2.4 网格材质映射
- PGSR 平面约束 → TSDF → 水密三角网格。
- 面片材质 = 邻域高斯按 α 加权投票的 argmax（边界低于阈值取众数）。
- 面片存 material_id → P.2040 查表（2.4/3.5/5.8 GHz 的 εr/σ/穿透损耗）。

## Stage 3 · 地图集成为 3D Tiles

- UAV 关键区材质 mesh + LOD1 底座 → 统一 UTM/WGS84。
- 转 **3D Tiles**（Cesium ion 或 GISBox），面片材质走 **Feature ID + 属性表**（`_batchTable`/`EXT_mesh_features`），供 UE 按面查材质。
- 输出 `coordinate_system.txt`（EPSG、local↔UTM/ENU 变换）。

## Stage 4 · Cesium for Unreal 仿真与对比验证（M5–M9）

对应开题研究内容③。

### 4.1 射线传播
- Cesium for Unreal 加载 3D Tiles，`CesiumGeoreference` 对齐 WGS84；`EnableDoubleSidedCollisions` + Complex Collision。
- `LineTraceByChannel` 取 `FHitResult` → 面 index → `UCesium3DTileset` 查 Feature ID → material_id → P.2040 参数。
- 三路径：
  - 直射 LoS：自由空间 `L=20log₁₀d+20log₁₀f+32.44`；
  - 一次反射：几何光学镜像点 + 菲涅尔(材质 εr, 入射角)，`L_ref=−20log₁₀|R|`；
  - 穿透：沿 R-tree 查穿透面，累加 P.2040 穿透损耗。
- **M8 修正**：明确"忽略绕射/多次反射"的适用边界；对 50m/密集区补一次刃形绕射(UTD)项或在结论中标注为已知局限。

### 4.2 2×3×3 全因子对比（M7）
- 地图类型：多源材质3DGS地图 vs ContextCapture 高精地图（基准）
- 场景密度：<20% / 20–50% / >50%
- 高度：50 / 100 / 200 m
- 每场景 10 m 网格接收点，中心发射。
- 指标：路损 RMSE/MAE；LoS 判断 准确率/精确率/召回率。
- **M9 修正**：基准材质由人工逐栋核验为主（SegFormer 仅辅助），与被测方法解耦。
- 交叉验证：典型场景 vs 3GPP TR 36.777 UMa-AV。
- 产出"采集效率提升 − 仿真精度代价"关系模型。

## 一句话给自己：诚实的边界

- 多源不是"3DGS 补全无影像区"，而是"免费底座 + UAV 关键区高精"的**异构精度拼接**——这正好是开题要研究的"效率-精度权衡"。
- 材质创新 = **可微联合**；投票版是安全垫，但必须在论文里说清哪个是贡献。
- 仿真在 Cesium-UE，Sionna RT 作第二工具交叉验证更稳。
